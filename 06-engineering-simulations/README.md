# 06 - Engineering Simulations

Software simulations that prepare for firmware and embedded-systems development without requiring physical hardware.

## Planned projects

1. Sensor Data Simulator
2. Device Status Monitor
3. Serial Command Parser
4. Battery Monitor Simulator
5. Traffic-Light State Machine
6. Bitwise Register Simulator

These projects will introduce device states, thresholds, command parsing, sensor data, state machines, and bitwise operations.
